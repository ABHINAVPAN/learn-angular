RxJS user details transfer

Component One sends user details through a shared RxJS Subject; Component Two receives them using the selected cleanup approach.

SubSink Subscription array takeUntilDestroyed

How it works

  1. Component One calls UserDetailsService.sendUserDetails().
  2. The service emits a typed user-details object through a plain RxJS Subject.
  3. Component Two subscribes and cleans up using the selected method.

Note: A plain Subject does not replay messages sent before subscribing.
