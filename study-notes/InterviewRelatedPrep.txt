What is Immutability?

An immutable object is an object whose state cannot be changed after it is created.

Once an immutable object is created:

✅ Values cannot be modified
 ✅ New values require creating a new object
 ✅ Thread-safe by nature
 ✅ Safe to share across multiple threads
 
String str = "Hello";
str.concat(" World");

System.out.println(str);
output:
Hello


Immutable Object
String str = "Hello";

str = str.concat(" World");

System.out.println(str);
output:
Hello World

creates a new object and the reference is updated.

Why is String Immutable?
Java designers made String immutable primarily for:

String Pool Optimization
Security
Thread Safety
HashMap Performance
Class Loading Safety

A Lambda Expression is a feature introduced in Java 8 that allows you to write anonymous functions (functions without a name) in a concise way.

It is mainly used to implement Functional Interfaces and enables functional programming in Java.

Syntax:
(parameters) -> { body }

Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("Thread Running");
    }
};

Runnable r = () -> {

Difference between map() and flatMap()?

MAP() vs FLATMAP() IN JAVA 8

1. map()

Definition:
- map() is used for one-to-one transformation.
- Each input element produces exactly one output element.
- It transforms data but does not flatten it.

Syntax:

Stream<R> map(Function<T, R> mapper)

Example:

List<String> names =
Arrays.asList("java", "spring", "angular");

List<String> result = names.stream()
                           .map(String::toUpperCase)
                           .collect(Collectors.toList());

Output:

[JAVA, SPRING, ANGULAR]

Flow:

java    -> JAVA
spring  -> SPRING
angular -> ANGULAR

One Input -> One Output


--------------------------------------------------

2. flatMap()

Definition:
- flatMap() is used when each element contains multiple elements.
- It transforms and flattens nested structures.
- Converts multiple streams into a single stream.

Syntax:

Stream<R> flatMap(
    Function<T, Stream<R>> mapper
)

Example:

List<List<String>> list = Arrays.asList(
    Arrays.asList("Java", "Spring"),
    Arrays.asList("Angular", "React"),
    Arrays.asList("SQL", "MongoDB")
);

List<String> result = list.stream()
                          .flatMap(x -> x.stream())
                          .collect(Collectors.toList());

Output:

[Java, Spring, Angular, React, SQL, MongoDB]

Flow:

Input:

[
 [Java, Spring],
 [Angular, React],
 [SQL, MongoDB]
]

After flatMap:

Java
Spring
Angular
React
SQL
MongoDB

Nested Lists -> Single Stream


--------------------------------------------------

3. map() vs flatMap()

Using map():

List<String> words =
Arrays.asList("Java", "Spring");

List<String[]> result =
words.stream()
     .map(word -> word.split(""))
     .collect(Collectors.toList());

Output:

[
 [J,a,v,a],
 [S,p,r,i,n,g]
]

Result remains nested.


Using flatMap():

List<String> result =
words.stream()
     .flatMap(word ->
         Arrays.stream(word.split("")))
     .collect(Collectors.toList());

Output:

[J, a, v, a, S, p, r, i, n, g]

Result becomes a single flattened list.


--------------------------------------------------

KEY DIFFERENCES

map()
------
- One-to-One Transformation
- Returns Stream<R>
- Does not flatten data
- Used for simple conversions
- Maintains original structure

flatMap()
----------
- One-to-Many Transformation
- Returns Flattened Stream<R>
- Flattens nested data
- Used for nested collections
- Removes one level of nesting


--------------------------------------------------

RETURN TYPES

map():

Stream<String>
      |
      V
map(String::length)
      |
      V
Stream<Integer>


flatMap():

Stream<List<String>>
          |
          V
       flatMap()
          |
          V
Stream<String>


--------------------------------------------------

COMMON USE CASES OF flatMap()

1. List<List<Integer>>

2. Department -> List<Employee>

3. Stream<String[]>

4. Optional<User>

5. Nested Collections


--------------------------------------------------

INTERVIEW ANSWER

map() is used for one-to-one transformation where each input element is converted into exactly one output element.

flatMap() is used when each element itself contains multiple values. It converts each element into a stream and then flattens all streams into one single stream.

In simple words:

map()     = Transform

flatMap() = Transform + Flatten


MEMORY TRICK

map()     -> One Input  -> One Output

flatMap() -> One Input  -> Multiple Outputs
             + Flatten Everything

1. WHAT IS STREAM API?

Stream API was introduced in Java 8 to process collections of data in a functional and declarative way.

Stream does not store data.
It processes data from a source such as:

- List
- Set
- Array
- Map
- File

Before Java 8:

Java 8:

- Less code
