Kubernetes:
Opene source container orchestration(Strategy planning) tool.
developed by google.
uses containers like docker.
helps manage containerized applications in different deployment environments.

1.because of microservices applications the need of it happened.
2. independent applications will be containerized and to manage number of containers it's use came.

what orchestration offers:
1. no downtime.
2. scalability or performance.
3. disaster recovery(backup and restore)

Kubernetes architecture:

                                  (Control plane/master node)
								  
								  workere nodes(1, 2, 3)           (kubelet process)
								  
						
Controle plane/mster node : 

1. Api Server : end points and k8's cluster.
2. Controller Manager : keeps track of whats happening in the container.
3. Scheduler: ensures PODS placement.
4. ETCD : Kubernetes backing store.

Virtual Network:
Maitains communications between master and worker nodes.
Makes them work like one unit. 


---- should be having multiple master nodes.

1. Pods: Smallest unit in kubernetes.
